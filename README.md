# Billing System

A C\# Billing System project developed for **CS 106 – Application Development & Emerging Technologies** at **Bicol University – College of Science, Computer Science Department**.

The project demonstrates the development of a billing management system through multiple laboratory activities, progressing from a Windows Forms desktop application to a mobile application using .NET MAUI.

## Desktop Application (Windows Forms)

The desktop version of the Billing System was developed using C\# Windows Forms and MySQL.

### Implemented Features

    - Secure login authentication and role-based access control
    - Customer management (Create, Read, Update, Delete)
    - Customer billing history and records viewing
    - Analytics dashboard with KPIs and charts
    - Audit logging and activity tracking
    - Export customer data to Excel and PDF
    - Change password with security validation
    - Modern Windows Forms UI with themes and status indicators
    - Permission management for Admin and Cashier roles
    - MySQL database integration
    - Local network database connectivity
    - Automated database backup and recovery support
    - Windows installer deployment using Inno Setup

### Technologies Used
    - C#
    - .NET Windows Forms
    - MySQL
    - MySql.Data
    - ScottPlot
    - EPPlus
    - PDF Export Libraries
    - Inno Setup 7
    - Visual Studio 2026

## Mobile Application (.NET MAUI)

The mobile version of the Billing System is being developed using .NET MAUI and .NET 10.

### Implemented Features

    - Customer Picker
    - Billing Month Entry
    - Previous Reading Entry
    - Present Reading Entry
    - Rate Per Cubic Entry
    - Auto\-computed Total Amount
    - Real\-time computation using TextChanged events
    - Numeric input validation using TryParse()
    - Invalid reading detection
    - Save Bill placeholder functionality

### Technologies Used

    - .NET MAUI
    - .NET 10
    - C#
    - XAML
    - Visual Studio 2026
